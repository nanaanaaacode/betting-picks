Betting Bot Playbook

What each sport actually bets, which markets it skips, and the daily run that produces it. Everything here mirrors the rules enforced in CLAUDE.md and the sanitizer.

The daily run

One planner sets the day's timing from the real schedule; the pick run is dynamic, not a fixed 5am.

01
Planner
Reads tomorrow's schedule, programs the pick + result one-shots. Pick = 1h before the first game; pulls earlier if an NBA/NHL game starts first.
~6pm prev day
02
Pick run
Pre-fetches MLB pitchers/odds + batting form + AFL/NBA/NHL/NRL/AFLW odds → full analysis → sanitize → Discord + dashboard.
~1h before 1st game · 5am fallback
03
NFL run
Separate job — the Sunday slate kicks ~3am AEST, before the main run. Own picks file + own Discord post.
~1h before kickoff
04
CLV capture
Snapshots each pick's closing line near game time — the leading edge indicator.
every 30 min
05
Result run
Grades every pick (ESPN / statsapi / Odds API scores), updates P&L, posts results + refreshes the dashboard.
~30 min after last game
06
Watchdog
Recovers a missed pick/NFL/result run and re-posts results that graded but never reached Discord.
6:30am + intervals
